# CAD (SolidWorks)

- `solidworks/Main_Incubator_Assembly.SLDASM` is the top-level assembly.
- An assembly file only references its parts. To open it in full, add the part files (`.SLDPRT`) into `solidworks/` next to it.
- Also export STEP and STL files for the shell, chamber, tray, bracket and gears so the design can be viewed and printed without SolidWorks.
- `Mechanical_Design_Proposal.pdf` has the design write-up.
